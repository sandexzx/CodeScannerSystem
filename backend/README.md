# Система учета товаров с отслеживанием файла данных сканера

Система для автоматического учета товаров с использованием сканера штрих-кодов и мониторинга файла данных.

## Требования

- Python 3.9 или выше
- Установленные зависимости из requirements.txt

## Установка

1. Клонируйте репозиторий или распакуйте архив
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Настройка

1. Создайте звуковые файлы в директории `sounds`:
   - success.wav - звук успешного сканирования
   - error.wav - звук ошибки (дубликат)
   - box_full.wav - звук заполнения коробки

2. Настройте параметры в файле `config.py`:
   - SCANNER_FILE_PATH - путь к файлу, куда сканер записывает данные
   - BOX_CAPACITY - вместимость коробки (по умолчанию 12 единиц)

## Использование

1. Запустите программу:
```bash
python main.py
```

2. В главном меню выберите нужное действие:
   - Начать мониторинг файла сканера
   - Показать текущие настройки
   - Изменить путь к файлу сканера
   - Выход

3. При запуске мониторинга:
   - Программа будет отслеживать изменения в файле сканера
   - При сканировании кода будет воспроизводиться звуковой сигнал
   - При обнаружении дубликата будет воспроизводиться звук ошибки
   - При заполнении коробки будет воспроизводиться специальный сигнал
   - Данные о коробках сохраняются в Excel-файл в директории export

## Логирование

Все действия системы записываются в файл `scanner.log` с временными метками.

## Экспорт данных

Данные о коробках и их содержимом автоматически экспортируются в Excel-файл в директории `export/boxes.xlsx`.

## Инструкция по работе с почтой (SMTP) — локальное использование

В проект добавлена возможность вручную отправлять сформированный Excel-файл по e‑mail. Ниже инструкция, откуда брать данные для популярных провайдеров и куда их вставлять в интерфейсе.

Общее (куда вставлять)
- В приложении откройте Settings → Настройки почты и отправка Excel.
- Поля:
  - SMTP Host — адрес SMTP‑сервера (пример: smtp.gmail.com или smtp.yandex.ru)
  - SMTP Port — порт (обычно 587 для STARTTLS, 465 для SSL)
  - Username — ваш логин (обычно полный e‑mail)
  - Password — пароль (рекомендуется создать и использовать password/app‑password)
  - Use TLS (STARTTLS) — включить для порта 587 (чекбокс)
  - From — адрес отправителя (обязательно)
  - To — адрес получателя (обязательно)
- Нажмите «Сохранить настройки почты», затем «Отправить последний Excel».

Рекомендации по провайдерам

1) Gmail (Google)
- SMTP host: smtp.gmail.com
- Port:
  - 587 — STARTTLS (обычно используйте этот и установите Use TLS = true)
  - 465 — SSL (Use TLS может оставаться true, но порт 465 использует SSL-соединение)
- Username: ваш полный Gmail‑адрес (например, your.name@gmail.com)
- Password: НЕ рекомендуется использовать основной пароль Google.
  - Включите двухфакторную аутентификацию (2FA) в аккаунте Google.
  - Создайте пароль приложения (App Password) в Google Account → Security → App passwords.
  - Используйте сгенерированный app password в поле Password.
- From: ваш Gmail‑адрес
- To: адрес, на который хотите отправлять Excel
- Примечание: Google запрещает доступ "меньше защищённых приложений". App Password — рекомендуемый способ.

2) Yandex
- SMTP host: smtp.yandex.ru
- Port:
  - 587 — STARTTLS (рекомендуется)
  - 465 — SSL
- Username: ваш полный Yandex‑адрес (например, user@yandex.ru)
- Password:
  - Рекомендуется использовать пароль приложения (если у вас включена 2FA) или создать пароль для внешних приложений в настройках Yandex.
  - Если 2FA не включена, можно использовать основной пароль, но безопаснее использовать пароль приложения.
- From: ваш Yandex‑адрес
- To: адрес получателя
- Примечание: проверьте, разрешён ли доступ к SMTP в настройках аккаунта Yandex.

3) Тестовый SMTP / локальный отладочный сервер
- Для разработки удобно использовать:
  - Mailtrap (он же SMTP‑testing) — даёт тестовые учётные данные, не доставляет письма конечным пользователям.
  - smtp4dev — локальный SMTP‑сервер для разработки (устанавливается отдельно).
- Mailtrap пример:
  - SMTP host: sandbox.smtp.mailtrap.io (или адрес, указанный в интерфейсе Mailtrap)
  - Port: 587
  - Username/Password: указаны в панели Mailtrap
  - From/To: любые тестовые адреса

Ошибки и отладка
- При ошибке отправки API вернёт сообщение об ошибке (HTTP 500) с причиной (например, аутентификация, таймаут, хост не доступен).
- Логи см. в консоли, где запущён backend (python backend/api.py).
- Частые проблемы:
  - Неправильный порт/хост.
  - Требуется включить TLS (STARTTLS) для порта 587.
  - Для Gmail — требуется app password и включённая 2FA.
  - Блокировка со стороны провайдера (проверьте настройки безопасности аккаунта).

Безопасность
- Приложение хранит SMTP‑пароль в файле `config.json` в явном виде. Для локального использования это удобно, но имеет риски:
  - Доступ к файлу даёт возможность отправлять почту от вашего имени.
  - Для повышения безопасности:
    - Используйте отдельный тестовый почтовый аккаунт с ограниченным доступом.
    - Используйте пароли приложений (app passwords) вместо основного пароля.
    - При необходимости интегрировать безопасное хранилище (Windows Credential Manager) — это улучшение можно добавить позже.

Пример заполнения (Gmail)
- SMTP Host: smtp.gmail.com
- SMTP Port: 587
- Username: your.name@gmail.com
- Password: (app password)
- Use TLS: true
- From: your.name@gmail.com
- To: recipient@example.com

Пример заполнения (Yandex)
- SMTP Host: smtp.yandex.ru
- SMTP Port: 587
- Username: user@yandex.ru
- Password: (app password or account password)
- Use TLS: true
- From: user@yandex.ru
- To: recipient@example.com
